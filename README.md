## Data Not in Repo

The **`data/`** folder is **not pushed** to the repo. Raw Open Library dumps are very large (e.g. editions ~59GB, works ~22GB). Even after converting to Parquet, the processed data is too large for typical Git commits.

**To run the pipeline locally:**

1. Download the dumps from **[Open Library Data Dumps](https://openlibrary.org/developers/dumps)** (or [Bulk Data](https://openlibrary.org/data)).
2. Place the required `.txt` dump files inside **`data/raw/`** in the repo root.
3. Run **`process_data.py`** (see Flow below). It will read from `data/raw/` and create **`data/processed/`** with Parquet files.

Required dump filenames (adjust dates to match the latest dump you download):  
`ol_dump_works_*.txt`, `ol_dump_editions_*.txt`, `ol_dump_authors_*.txt`, `ol_dump_ratings_*.txt`, `ol_dump_reading-log_*.txt`.  
Update the date in `src/process_data.py` if your filenames differ (e.g. `2025-12-31`).

---

## Flow (single read)

1. **Raw → Parquet**  
   **`src/process_data.py`** reads TSV+JSON dumps from `data/raw/`, uses schemas in `src/` to extract the needed JSON fields with **Polars**, and writes Parquet under `data/processed/`.  
   **Why Parquet:** Raw dumps are huge; Parquet gives compression and columnar reads. CSV would be larger and slower for this volume.

2. **Cleaning & feature engineering**  
   Notebooks in **`notebooks/`** load Parquet from `data/processed/`, clean (nulls, dates, dedup), and write `*_cleaned.parquet` and reports under **`reports/`**.

3. **Popularity & rank**  
   **`04_01_build_overall_rank.ipynb`** builds the overall popularity score and rank table (`overall_rank.parquet`).

4. **Visualizations**  
   **`visualization_story.ipynb`** produces all charts and saves them as HTML in **`figures/`**. The final report HTML embeds or references these.

5. **Final report**  
   **`blog_the_long_tail_of_literature_punamkumari.html`** is the standalone report (narrative + takeaways). Open it in a browser to view.

## What Each Script / Notebook Does

### `src/` (Python)

| File | Purpose |
|------|--------|
| **process_data.py** | Reads dumps from `data/raw/`, extracts JSON fields via Polars and the schemas below, writes Parquet to `data/processed/` (works, editions, authors, ratings, reading_log). Skips missing files. |
| **work_schema.py** | Polars struct schema for Works JSON (title, authors, subjects). |
| **edition_schema.py** | Schema for Editions JSON (publish_date, works, etc.). |
| **author_schema.py** | Schema for Authors JSON (name, etc.). |

### Notebooks (`notebooks/`)

| Notebook | Purpose |
|----------|--------|
| **03_01_feature_engineering_authors_pandas.ipynb** | Load authors Parquet, clean, validate; output `authors_cleaned.parquet` and data quality report. |
| **03_02_feature_engineering_editions_pandas.ipynb** | Clean editions, derive publish year; output `editions_cleaned.parquet` and report. |
| **03_03_feature_engineering_ratings_pandas.ipynb** | Clean ratings; output `ratings_cleaned.parquet` and report. |
| **03_04_feature_engineering_reading_log_pandas.ipynb** | Clean reading log, add log year; output `reading_log_cleaned.parquet` and report. |
| **03_05_feature_engineering_works_pandas.ipynb** | Clean works (e.g. subjects); output `works_cleaned.parquet` and report. |
| **04_01_build_overall_rank.ipynb** | Merge ratings + reading log, compute Bayesian rating and popularity score, rank; output `overall_rank.parquet` and report. |
| **visualization_story.ipynb** | Builds all charts (long tail, Lorenz, age gap, heatmap, sleeping beauties) and saves HTML into `figures/`. |

Reports written by the above notebooks are saved under **`reports/`**.

## Setup and Run

```bash
# Install dependencies
pip install -r requirements.txt

# 1. Put Open Library dumps in data/raw/ (see "Data Not in Repo" above)

# 2. Raw → Parquet (from repo root)
python src/process_data.py

# 3. Run notebooks in order: 03_01 … 03_05, then 04_01, then visualization_story.ipynb
#    (Jupyter or VS Code). Outputs go to data/processed/, reports/, and figures/.

# 4. Open the final report
open blog_the_long_tail_of_literature_punamkumari.html   # macOS
# Or double-click the file in your file manager.
```
